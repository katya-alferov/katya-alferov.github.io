# Portrait

No portrait is used yet. To add one Katya has chosen:

1. Save it here as `portrait.jpg` (around 800×1000 px, 4:5 portrait crop).
2. In `src/content/profile.ts`, set
   `portrait: { src: "/images/portrait.jpg", alt: "Portrait of Katya Alferov" }`.

It appears in the hero beside the location label, served through `next/image`.
